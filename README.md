# 전세계 분쟁 지도 (World Affairs Map)

세계 여러 분쟁 소식을 여러 사이트에서 찾아다닐 필요 없이, 한곳에서 지도로 볼 수 있도록 만든 한국어·영어 웹사이트입니다.

## 주요 기능

- **3D·2D 지도:** 드래그로 돌리고 휠로 확대·축소하는 지구본, 평면 지도 전환
- **34개 지역:** 전쟁, 무력 충돌, 긴장 지역, 조직범죄 분쟁, 외교 분쟁, 사회 불안
- **지역 상세:** 배경, 당사자, 추세(악화·경보·유지), 관련 기사
- **오늘의 전쟁 위험 지수:** 10점 척도와 판단 근거
- **일일 브리핑:** 날짜별 주요 소식과 출처
- **산업 이슈:** 분쟁과 공급망이 자동차 산업에 미치는 영향
- **관심 목록:** 자주 보는 지역 저장(브라우저에 저장)

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 별도 설치나 서버가 필요 없습니다.
국경선 데이터와 사진은 인터넷에서 불러오므로 온라인 상태에서 여세요.

## 만든 방법

기획과 기능 방향은 직접 정하고, AI(Claude)로 코드를 작성했습니다.
지구본은 WebGL로 브라우저에서 직접 그리며, 국경선은 공개 세계 지도 데이터(ECharts world map)를 사용합니다.

## 출처와 유의사항

- 기사: Al Jazeera, UN News, AP, Reuters, AFP 등 각 기사에 출처 표시
- 추세: Crisis Group CrisisWatch 월간 평가와 최근 보도를 바탕으로 한 편집자 판단
- 사진: Wikimedia Commons (각 사진의 라이선스와 작성자 표기 조건을 확인하세요)
- 위험 지수, 브리핑, 추세는 자동 갱신되지 않으며 작성 날짜 기준입니다.
- 투자 조언이 아닙니다.
